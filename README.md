# Challenge3
Online Shopping Calculator.

Problem Statement:
A student is purchasing items from an online store. Read the purchase amount, customer type (1 = Student, 2 = Regular Customer),
and delivery distance in kilometres. Determine the discount and delivery charge using conditional statements. Display the purchase
amount, discount amount, amount after discount, delivery charge, and final payable amount.

Algorithm:
1.Start
2.Declare variables type, mrpprice, discount, distance, distancecharge, and finalprice.
3.Read the customer type, MRP price, delivery distance.
4.Check the customer type, purchase amount and delivery charge by using the if and else-if conditional statements.
5.Calculate the final price and display it.
6.Stop
